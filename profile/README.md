# Gridex-kb

기술·표준 지식창고와 지식창고 생성 도구를 관리합니다. 출처와 근거를 추적하고 원문 보관과 공개 지식을 구분합니다.

## GRIDEX 조직 안내

- [Gridex-Korea](https://github.com/Gridex-Korea) — GRIDEX의 기존 통합 업무·연구 저장소와 공통 프로젝트를 관리합니다.
- [Gridex-Ent](https://github.com/Gridex-Ent) — 행사 운영과 참여형 콘텐츠를 위한 도구를 관리합니다.
- [Gridex-forks](https://github.com/Gridex-forks) — 외부 오픈소스의 검토·실험을 위한 포크를 관리합니다.
- [Gridex-Workware](https://github.com/Gridex-Workware) — 업무 공간, 사내 업무 시스템과 문서·데스크톱 생산성 도구를 관리합니다.
- [Gridex-maps](https://github.com/Gridex-maps) — 재생에너지와 전력 분야의 지도·공간정보 프로젝트를 관리합니다.
- [Gridex-policy](https://github.com/Gridex-policy) — 에너지 정책 지식창고와 제도 해설 도구를 관리합니다.
- [Gridex-Engineering](https://github.com/Gridex-Engineering) — 전력계통 엔지니어링과 해석·검증 도구를 관리합니다.
- [Gridex-HW](https://github.com/Gridex-HW) — HILS 플랫폼과 광 링크·장비 연동 프로젝트를 관리합니다.
- [Gridex-SW](https://github.com/Gridex-SW) — GRIDEX의 소프트웨어 프로젝트를 위한 조직입니다.

## 이용 안내

프로젝트의 실행 방법·개발 상태·검증 범위는 각 저장소의 README를 확인하세요. 공개 자료의 이용 조건은 저장소별 라이선스를 따릅니다. 비공개 업무 자료와 원문 보관 자료는 이 대문에 게시하지 않습니다.
